01 / The chain nobody sees

A heatwave doesn’t cause a health crisis. A chain does.

Heat stresses fodder jowar in its vegetative stage. Fodder yield falls, the fodder mandi price jumps, debt-stressed farm labourers work longer in unsafe heat, and about three weeks later it shows up as heat-stress illness. Every department sees only its own link.

  1. heatwave STRESSES
  2. fodder_jowar_vegetative REDUCES_YIELD_OF
  3. fodder SHOCKS_PRICE_AT
  4. mandi_fodder PRESSURES
  5. farm_laborers AT_RISK_OF
  6. heat_stress_illness

5 hops, typed, weighted and sourced edges in FalkorDB. Lag along the corridor: 21 days.

02 / Agents propose. The graph disposes.

Hypotheses are graph writes, not chat messages.

Weather, agronomy and health agents write (:Hypothesis) nodes, then support or attack each other’s with evidence edges. An in-graph fixpoint decides what survives. An agent that was wrong last season is discounted automatically.

weatheragronomyhealth 
defeated  if attack ≥ support + 0.5·eff
accepted  if eff + support − attack ≥ 0.6

Season 2025 (synthetic): agronomy’s wheat hypothesis is defeated. Attack 0.47 and its credibility fell 0.50 → 0.40 after a 2024 miss.

03 / Memory that rewires

close_episode() writes outcomes back, so next season changes.

Every recommendation is an (:Intervention) wired to its observed outcome. When a season closes, success rates update, failed precedents are visibly defeated, and agent credibility moves. Run 2024, close it, and run 2025: the recommendations change because of memory.

04 / Refusal as a feature

No precedent, no evidence. No action.

The dairy branch has no targeting intervention in the precedent graph. Sentinel won’t make one up. It turns the path grey and hands it to a human.

UNPRECEDENTED heatwave › dairy_cattle › milk › dairy_collection › dairy_households → escalate to district officer
  • act: precedent P ≥ 0.5
  • weak analog: similar episodes, nothing to act on (amber)
  • defeated precedent: struck through
  • unprecedented: grey, escalated

cd cascade-sentinel
pip install -e ".[dev,embedded]"   # Python 3.12+

Honest limits

One corridor (heat → labour → illness) plus a dairy branch. The districts and data are synthetic archetypes, not a live feed. Adjudication is a prototype. There hasn’t been a production season of write-backs yet. The optional LLM only writes the rationale paragraph; decisions never read it.
