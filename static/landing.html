How a cascade becomes a crisis

Climate shocks become human crises through chains. A heatwave stresses a crop at a specific growth stage, which cuts fodder, prices move, debt-stressed farm labourers work longer in unsafe heat, and about 3 weeks later it shows up as heat-stress and water-borne illness. Each department sees only its own link, so by the time health data shows the signal, the cheap intervention windows 15–45 days earlier have closed.

How it works

Remove FalkorDB and nothing is left. Every agent tool is a graph operation: traversal, precedent matching, adjudication, refusal, and write-back.

1

Enumerate cascade paths

3–5 hop typed graph traversal from the forecast hazard to health outcomes, ranked top K = 6. 1–2 hop direct-exposure paths are listed separately.

2

Agents debate

Weather, agronomy and health propose hypotheses, then support or attack each other on the same subgraph.

3

Graph adjudicates

Defeat if attack ≥ support + 0.5·eff. Accept if eff + support − attack ≥ 0.6.

C = (hits+1)/(hits+misses+2)
4

Precedent-gated action

Act only if analog similarity ≥ 0.5 and P ≥ 0.5. Otherwise UNPRECEDENTED: escalate to district officer.

P = ((successes+1)/(trials+2)) × 0.9^max(0, year−last−1)

Close the episode to write held-out outcomes back (intervention trials/successes/P, agent hits/misses/credibility). The next season changes because of memory.

Memory that changes decisions

Closing 2024 writes held-out outcomes into FalkorDB. Semantic = who this district is; episodic = what happened this season; procedural = which interventions were tried and how they scored. Talk to the graph from any MCP client

stdio, or python -m sentinel.mcp_server --http 8765 (streamable HTTP). 11 tools, all graph operations.

enumerate_cascade_paths

Rank 3–5 hop cascade paths (top K) and return 1–2 hop direct-exposure paths from the episode forecast's hazard to health outcomes.

query_precedent

Find analog closed episodes and intervention history for a cascade path.

propose_hypothesis

Write an agent hypothesis about a path and MERGE the MAY_TRIGGER edge.

support_hypothesis

Assert supporting evidence on a hypothesis.

attack_hypothesis

Assert attacking evidence on a hypothesis.

compute_accepted_risk

Adjudicate hypotheses to accepted / contested / defeated by the in-graph fixpoint.

recommend_action

Recommend interventions with precedent, or escalate UNPRECEDENTED paths.

close_episode

Reveal held-out outcomes, write back trials and credibility. Idempotent.

explain

Explain a recommendation: path, analogs, precedents, defeated rivals, Cypher, owner.

memory_view

Counts and samples of an episodic, semantic, or procedural memory layer.

graph_snapshot

Cytoscape elements for the episode graph with status and layer classes.

Honest limitations

  • One corridor (heat → labour → illness) plus a dairy distractor.
  • Synthetic archetype data, not a live district feed.
  • Prototype adjudication (fixpoint, Gauss–Seidel by credibility).
  • No production season of write-backs yet.
  • LLM (optional) writes a rationale paragraph only; default provider is none.
